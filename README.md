# AI 智能叫卖助手 · MVP

面向流动摊贩、菜市场商户的中文叫卖音频工作台，提供商品信息录入、**三种风格文案生成（本地模板）**、多音色在线 TTS、试听、循环播放、MP3 下载。

## 立即体验

将 `public/index.html` 用 Chrome 或 Edge 打开：**无需安装**即可生成三种文案并使用系统语音试听。

浏览器自带的 Web Speech API 无法导出音频数据。**MP3 下载需要 Node.js TTS 服务**：

```bash
npm install
npm start
```

浏览器打开 http://localhost:3000

可以使用 `PORT=4321 npm start` 修改端口。国内网络需要代理时：`TTS_PROXY=http://127.0.0.1:7890 npm start`（Windows PowerShell：`$env:TTS_PROXY="http://127.0.0.1:7890"; npm start`）。此处使用 Node 服务自身可访问的代理地址。

## 产品功能

- 默认商品：红富士苹果，5 元一斤；卖点：新鲜到货
- 一键生成 3 种风格的营销话术，逐条可手动编辑、复制、选用
- 6 种声音预设：东北热情大哥（**普通话男声音色 + 东北风格文案，非真实方言**）、辽宁方言女声、亲切女声、活泼小哥、陕西方言女声、广播男声
- 音频试听优先请求 Node 服务在线神经 TTS；服务不可用则回退到浏览器系统语音
- 循环播放、可选 2 / 4 / 6 秒间隔；语速调节；停止播放
- 在线模式：生成、下载 MP3；离线打开 HTML：明确提示下载需要服务，不提供虚假导出
- 表单和选项保存在浏览器本地存储（不保存播放中的音频）

## 技术实现

`public/index.html` 使用零框架 HTML/CSS/JavaScript，适合直接二次开发；`server.mjs` 使用原生 Node HTTP Server。MP3 由 [node-edge-tts](https://github.com/SchneeHertz/node-edge-tts) 提供在线合成服务，服务端按文本/音色/语速进行有限的内存缓存。

边界：现阶段的文案生成采用显式模板，不需要 LLM API Key，未接入真实大模型；在线 TTS 属于第三方非正式接口，依赖外网，可能有访问限制和可用性变化，不建议直接作为商业产品的服务等级保证。上线建议改接有授权的正式云 TTS API，并补充额度限制、账号、日志、审核、定价、隐私和商用条款。

本项目使用原创抽象播音音色名称，不克隆演员声音。用户自行核实产品价格与卖点，不应使用虚假宣传，播放时须遵守当地商业噪声管理要求。

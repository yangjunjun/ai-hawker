# Changelog

## 0.2.0

- Independently configurable MiMo copy generation and speech synthesis, retaining local templates and Edge MP3 by default.
- MiMo non-streaming WAV with explicit voice/format/rate capabilities; accurate download filenames.
- Explicit public API base URL for Pages, same-origin Node discovery and static fallback.
- Preserve drafts on failure; abort stale generation/playback; safe error responses and bounded concurrency, response sizes and caches.
- Environment sample, lockfile, API/deployment documentation, Node contract tests and Chromium regression workflow.

Live MiMo account access, audio quality and direct MP3 support have not been verified. No API credentials are shipped.
